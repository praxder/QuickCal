# Project Overview

QuickCal is currently a seed repo for a macOS utility app named QuickCal: "A Speedy Way to Add Calendar Events in Natural Language." The repo has no app scaffold yet. Existing tracked files are README.md and openspec/config.yaml. OpenSpec is configured with schema: spec-driven, but no changes directory exists yet.

User-provided design assets for the initial UI exploration live outside the repo at /Users/adam/Downloads/stitch_natural_event_entry/. That folder contains DESIGN.md, code.html, and screen.png for the "Quick Event Main Page - Dark" concept.
