# Style And Conventions

Project-level coding conventions are not established yet because there is no app code. User-provided AGENTS.md guidance applies: prefer small incremental changes, study existing context first, keep functions small and boring, use TDD when possible, and make the minimal change needed.

For the Stitch dark main page design, current visual direction is macOS-native dark utility: compact Inter/SF-like typography, dark charcoal surfaces, subtle outlines, 8px component radii, 16px larger modal radius, macOS accent blue for primary action/focus, and dense but organized spacing.
